## Hi👋

I build across the stack, from web and mobile interfaces to backend
services and cloud deployments (most of them are private for obvious reasons or under work account). I enjoy understanding how the pieces
fit together and turning an idea into something people can actually use.

At **Volvo Group**, my experience spans innovation projects and
Vehicle Data Services. My current role focuses on backend engineering,
building on my experience with React, Next.js, React Native,
TypeScript, Java and Spring.

In 2026, I completed my **master's in Applied Data Science** alongside
working full time. I'm interested in bringing software engineering
and machine learning together to solve practical problems.

## What I build

📱 **Web & mobile applications**  
Interfaces, user flows and product features with React, Next.js,
React Native and TypeScript.

⚙️ **Backend services & APIs**  
Java and Spring services, vehicle data flows, integrations,
monitoring and troubleshooting.

☁️ **Software that runs beyond my laptop**  
Working with AWS, Docker and Kubernetes across development
and deployment.

🧠 **Data science & machine learning projects**  
Python experiments, model evaluation and research into how
large language models handle time-sensitive information.
